# bluetooth_relay_gyro_accel_mech_car_kinda
This is an attempt at making a gyroscopic remote control mechanum wheel car, but this is also an excellent example of alternate thinking to complete a task. This will go over serial port communication using a python relay paired with two arduinos one acting as a remote and one as the car. 
This project also uses a relay to get incoming data from one port to another. 
If this code is used on your computer the relay code must be changed a little to match the names of your serial ports on your computer. Even though bluetooth port communication failed all other parts of this project were a success
